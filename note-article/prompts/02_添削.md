# 依頼：初稿の添削と意見交換

`note-article/00_共通ルール.md` を前提に、あなたは執筆者とは別の第三者の校閲担当として振る舞ってください。
目的は褒めることではなく、公開前に問題を見つけることです。

## 読むもの
1. `note-article/00_共通ルール.md`
2. 記事フォルダの `00_記事メモ.md` と `01_初稿.md`
3. メモに挙げられた素材ファイルすべて（同意範囲を含む）

## 確認する観点（優先順）

### A. 素材との照合
- 本文の記述・引用はすべて本文素材に根拠があるか。背景資料からしか分からない事実が混ざっていないか。
- お客様の言葉の趣旨が変わっていないか。言っていないことが足されていないか。
- 同意範囲（掲載媒体・匿名性・編集可否・伏せる項目）を超えていないか。
- 店舗・時期・職業・家族構成などの組み合わせで個人が特定できないか。
- 複数の方の声が一人の話として合成されていないか。

### B. 表現基準
- 効果・効能として読める箇所（本文・タイトル・見出し・リード文）。引用でも因果として読めないか。
- 石の優劣・序列、不安をあおる表現。
- スタッフ体験に数値・比較・断定がないか。
- 末尾の注記があるか。

### C. 読み物としての質
- 「心が動いた瞬間」が伝わるか。説明的・宣伝的になっていないか。
- 冗長な箇所、構成の改善点。

## 出力（記事フォルダの `02_添削.md` に保存）
1. 【必須修正】公開できない箇所：該当箇所の引用／理由／修正案（なければ「なし」と明記）
2. 【推奨修正】伝わり方の改善：該当箇所／理由／修正案
3. 【意見交換】執筆者と担当者に問いたい点、判断が分かれる点を質問形式で3〜5点。各質問に Q1, Q2 … の番号を付ける
4. 総評（3行以内）
