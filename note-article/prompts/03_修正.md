# 依頼：添削をふまえた修正

`note-article/00_共通ルール.md` に従い、記事フォルダの添削と担当者の回答を受けて修正版を作成してください。

## 読むもの
1. `01_初稿.md`
2. `02_添削.md`（第三者校閲からの添削）
3. `03_担当者回答.md`（意見交換への担当者の回答）
4. 必要に応じて素材ファイル

## 進め方
1. 【必須修正】はすべて反映します。反映できない場合は理由を書いてください。
2. 【推奨修正】は採用・不採用を判断し、理由を一行ずつ添えてください。
3. 【意見交換】は担当者の回答に従います。回答のない項目は、より慎重な側を選んでください。
4. 修正によって素材にない内容を足さないでください。

## 出力
- `04_修正版.md`：タイトル・本文・末尾注記（そのまま note に貼れる形）
- `05_変更一覧とチェック表.md`
  1. 変更一覧：添削項目ごとに「反映／不採用（理由）」
  2. 最終セルフチェック表（共通ルール全項目）
  3. 公開前に人が確認すべき残りの懸念点
