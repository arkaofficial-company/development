# note「お客様体験レポート」作業フォルダ

アルカダイアモンド公式noteの記事を、Claude Code で「初稿 → 第三者添削 → 修正」の流れで作るための作業場です。
ルールの元は企画書（2026年9月19日）の3章・4章・8章です。

## フォルダ構成

| 場所 | 中身 |
| --- | --- |
| `00_共通ルール.md` | 素材の扱い・表現基準・文体。全工程の前提 |
| `prompts/` | 初稿作成・添削・修正の3つの指示文 |
| `素材/本文素材/` | noteでの公開同意を確認済みのお客様の声だけを置く |
| `素材/背景資料/` | 日報・測定記録。状況理解のためだけで、本文には使わない |
| `素材/スタッフ体験/` | スタッフ本人の了承を得た社内トライアルの記録 |
| `原稿/` | 記事ごとのフォルダ。`_テンプレート` を複製して使う |
| `../.claude/agents/note-reviewer.md` | 添削を担当するサブエージェントの定義 |

## 進め方

1. **素材を置く**
   `素材/本文素材/_テンプレート.md` を複製し、お客様の声と同意範囲を書き込む。
   ファイル名は `V001_きっかけの一言.md` のように、データベースの管理番号と短い見出しにする。
   氏名などの個人情報はファイル名にも書かない。
2. **記事フォルダを作る**
   `原稿/_テンプレート` を複製し、`原稿/2026-11_記事の仮題/` のように名前を付ける。
   `00_記事メモ.md` に、使う素材ファイルと記事の方向性を書く。
3. **初稿を書く（メインのセッション）**
   Claude Code に次のように依頼する。
   ```
   note-article/prompts/01_初稿作成.md に従って、原稿/2026-11_〇〇/ の初稿を書いて
   ```
   結果は `01_初稿.md` に保存される。
4. **添削する（サブエージェント）**
   ```
   note-reviewer で 原稿/2026-11_〇〇/ の初稿を添削して
   ```
   添削役は書き手の会話を見ず、ルール・素材・初稿だけを読んで `02_添削.md` に書く。
5. **意見交換に人が答える**
   `02_添削.md` の【意見交換】の質問に、担当者が `03_担当者回答.md` で答える。
   採否を決めるのは人です。AI同士で合意させない。
6. **修正版を作る（メインのセッション）**
   ```
   note-article/prompts/03_修正.md に従って、原稿/2026-11_〇〇/ を修正して
   ```
   `04_修正版.md` と `05_変更一覧とチェック表.md` が保存される。
7. **承認と記録**
   `04_修正版.md` と `05_変更一覧とチェック表.md` を関係者の承認に回す。
   公開後はデータベースに掲載先と公開日を記録する。取り下げ依頼の際にこのフォルダから追える。

## 注意

- 本文素材が空の記事フォルダでは、初稿を書かずに止まるようにしてある。日報だけで記事は作らない。
- このフォルダは社内資料です。お客様の声の原文を含むため、公開リポジトリに置かないこと。
